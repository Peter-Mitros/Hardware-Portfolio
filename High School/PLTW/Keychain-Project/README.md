## Project Overview
This project involved designing a custom ND logo keychain in Autodesk Fusion according to specific dimensional and manufacturing constraints for a PLTW Engineering assignment. The project required translating graphical characteristics into a 3D model and preparing the file for manufacturing and documentation.

* **Software Used:** Autodesk Fusion
* **Course:** PLTW Introduction to Engineering Design
* **Primary Features:** Parametric extrusion, sketch constraints, hole clearance alignment

## Design Constraints and Parameters
* **Volumetric Envelope:** Designed to fit strictly within the required maximum boundary dimensions of 3.0 in x 2.0 in x 2.0 in.
* **Hardware Clearance:** Features an integrated attachment hole sized precisely to accommodate a standard 0.09-inch diameter ball chain.
* **Technical Documentation:** Completed a corresponding annotated multiview drawing using CAD software to define orthographic projections and dimensional tolerances.
