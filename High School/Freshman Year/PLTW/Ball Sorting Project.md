# PLTW Ball Sorting Project

This prototype was built for a design challenge in the Introduction to Engineering Design (IED) curriculum. The objective was to create a reliable system that sorts and collects small spheres into two separate containers to maximize the final performance score.

## Performance Summary
* **System Accuracy:** 92% successful distribution rate across all testing trials. 

## Project Specs

| Parameter | Measurement | Notes |
| :--- | :--- | :--- |
| **Length** | 11.0" | Cardboard base dimensions |
| **Width** | 10.5" | Cardboard base dimensions |
| **Height** | 6.5" | Measured to the top of the highest cup |
| **Capacity** | 16.0 oz | Volume per container |

## Key Design Choices
* **Staggered Heights:** The containers are positioned at different levels to use gravity to move the spheres from the top section to the bottom section automatically.
* **Popsicle Stick Guide Rails:** Parallel popsicle sticks are taped together to form a ramp. This acts as a track to keep the spheres rolling straight without falling off the sides.
* **Secured Foundation:** Both cups are anchored directly to a flat cardboard sheet to keep the entire structure stable and aligned during testing runs.
* **Sizing:** The design is meant to be as minimal as possible and as cost-aware as possible for a more affordable design in the parameters of our project.

## Testing & Troubleshooting
* **Initial Problem:**
* Glue was not allowed to be used in construction 
* The popsicle sticks weren't entirely measured properly to be able to make a perfecly accurate ramp
* **Implemented Solution:**
* Cut and measured small pieces of tape and rolled it to substitue for glue

* Marked where the sticks would go, then used a razor to perfectly cut precise parts of the sticks off for a more perfect ramp

## Future Improvements
If given the opportunity for a secondary design iteration, the following changes would be made:
* Move the popsicle sticks from laying flat to laying sideways to ensure more accurate sorting (small balls would fall more easily)
* Make a feature that allows easy access once the balls have been sorted for multiple tries
